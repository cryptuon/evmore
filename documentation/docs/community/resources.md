## Getting Help

### Self-Help Resources

Before asking for help, try these resources:

1. **Documentation** (you're here!)
   - [FAQ](../getting-started/faq.md) - Common questions
   - [Troubleshooting](../getting-started/troubleshooting.md) - Problem solving
   - [Mining Guide](../mining/mining-guide.md) - Mining help

2. **Search existing discussions**
   - GitHub Issues - technical problems
   - Discord search - community solutions

3. **Block explorers**
   - Etherscan for transaction details
   - Verify contract addresses

### Getting Support

**For general questions:**
1. Check the FAQ first
2. Ask in Discord #help channel
3. Be specific about your issue

**For technical bugs:**
1. Search GitHub Issues
2. Create a new issue if not found
3. Include:
   - Clear description
   - Steps to reproduce
   - Error messages
   - System information

**For security issues:**
- Do NOT post publicly
- DM trusted moderators on Discord
- Email security contact (if available)

### What to Include When Asking for Help

Good help requests include:
- [ ] What you're trying to do
- [ ] What you expected to happen
- [ ] What actually happened
- [ ] Error messages (copy/paste, not screenshot)
- [ ] Transaction hash (if applicable)
- [ ] Steps you've already tried

## Safety and Security

### Official Verification

Always verify you're using official resources:

| Type | How to Verify |
|------|---------------|
| Contract address | Check official docs, multiple sources |
| Website | Use bookmarks, check SSL |
| Discord | Verify server info, watch for imposters |
| Social media | Check follower counts, verification |

### Common Scams to Avoid

1. **Fake support** - Real support never DMs first
2. **Giveaway scams** - "Send 1 ETH, get 2 back" is always fake
3. **Phishing sites** - Always verify URLs
4. **Fake tokens** - Don't interact with unknown tokens
5. **Impersonators** - Verify usernames exactly

### Reporting Scams

If you encounter a scam:
1. Don't engage
2. Screenshot evidence
3. Report to moderators
4. Warn the community
