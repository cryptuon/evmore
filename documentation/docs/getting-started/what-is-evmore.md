# What is EVMORE?

EVMORE is **digital gold** - a cryptocurrency that replicates the economic properties of physical gold using blockchain technology and a revolutionary proof-of-work algorithm called KeccakCollision.

## The Vision: True Digital Gold

For 5,000 years, gold has served as humanity's most trusted store of value. Its scarcity, durability, and the real effort required to extract it from the earth have made it the ultimate monetary asset. EVMORE brings these same properties to the digital world.

### Why "Digital Gold" Matters

Traditional cryptocurrencies have limitations:
- **Bitcoin**: Dominated by industrial ASIC miners, making it inaccessible to regular people
- **Ethereum**: Moved to Proof-of-Stake, where the wealthy earn more by already having more
- **Other tokens**: Often pre-mined, centralized, or without real scarcity

EVMORE solves these problems by creating genuine digital scarcity through computational work that anyone can participate in.

## How EVMORE Works

### The KeccakCollision Algorithm

Unlike traditional mining that just looks for hashes with leading zeros, EVMORE requires miners to solve **collision puzzles**:

1. The network provides a **challenge** - a unique puzzle derived from blockchain data
2. Miners must find **4 different values** that all produce the same hash pattern
3. These values must be submitted in ascending order
4. Valid solutions earn mining rewards

This approach has key advantages:

| Property | Traditional Mining | EVMORE Mining |
|----------|-------------------|---------------|
| Hardware | ASIC-dominated | GPU/CPU accessible |
| Memory | Low requirements | Memory-hard (needs RAM) |
| Verification | Simple | Smart contract verified |
| Fairness | Industrial advantage | Consumer hardware viable |

### Memory-Hard Design

The KeccakCollision algorithm requires significant memory bandwidth:
- Prevents specialized ASIC hardware from dominating
- Makes GPU and CPU mining competitive
- Ensures decentralized participation
- Reduces energy waste compared to brute-force mining

### On-Chain Verification

Every mining solution is verified by smart contracts on-chain:
- Transparent and auditable
- No trusted third parties
- Enables smart contract integration
- Creates a permanent, verifiable record
