# EVMORE Documentation

**Scarce. Mineable. Programmable.** EVMORE is a 21-million-supply, proof-of-work token on Ethereum powered by the KeccakCollision mining algorithm.

| Parameter | Value |
|-----------|-------|
| Max Supply | 21,000,000 EVMORE |
| Token Standard | ERC-20 |
| Mining Algorithm | KeccakCollision |
| Block Reward | 50 EVMORE (halves every ~4 years) |
| Block Time | ~10 minutes |

| Premine | None (100% fair launch) |
